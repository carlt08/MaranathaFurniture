# Image attributions

All photographs in this project are **temporary demonstration images** and are **not photographs of Maranatha Furnishers' real stock**. They are stock photos used only to show how the website will look. Replace them before the website is used for real sales (see the README).

- Source: [Unsplash](https://unsplash.com), images served from `images.unsplash.com`.
- Licence: [Unsplash License](https://unsplash.com/license). It allows free use, including commercial use, without permission. Attribution is not required but is appreciated.
- Processing: each photo was downloaded at up to 1600 px wide, cropped to 4:3 (or the hero ratios) and converted to WebP. Product "-2" images are close-up crops of the same photo, not separate photographs.
- Photographer names were **not recorded** during download. Before launch, replace these images with the shop's own photos, or look up each photo ID on Unsplash and add the photographer credit here.

Source URL pattern: `https://images.unsplash.com/photo-<photo id>`
